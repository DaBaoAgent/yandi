### 三个系统级缺陷（都已修，教训通用）

1. **`CUTS[0]` 不是 0**：样片 cues.cuts 首项是第一个切点，全片 CUTS[0]=5.115。场景里写 `t - CUTS[j]` 当起点会让时相整体偏移 5–10 秒，表现为"动画元素迟迟不出现、数字停在初值"。正解：`SHOT_T(j) = j<=1 ? 0 : CUTS[j-2]`，`SHOT_L(j) = CUTS[j-1] - SHOT_T(j)`
2. **`panel()` 默认填充用 M(0) 在夜景等于隐形**：卡片、判词条、战报条整块看不见。填充至少 M(1)，描边 M(6)
3. **边缘受光不能边扫边写**：`if (get(x-1,y) !== base) px(x,y,lit)` 从左往右扫时，第一个像素被提亮后，右侧每个像素的左邻都不再等于 base，条件沿整行自传播 → 整个剪影被刷成亮色（五座坟曾变成"花盆"）。必须先收集边缘像素再统一上色

## 字幕与口播对不上：根因与修法（20:35）

- **根因**：`配音.json` 的 7 个 chunk 的 `start`/`duration` 是**名义值**，不是实际语音分段。chunk 3 标称 57–97 s、206 字（5.15 字/秒），而全片实际 6.58 字/秒。按 chunk 网格做字数比例分配，偏差 p50 **13.3 s**、max **18.2 s**、102 条里 96 条偏差 >0.4 s——不是"差半拍"，是整段错位。旧版靠 78% 静音吸附救回一部分，剩下 22% 保留原误差
- **修法**：词级强制对齐（`tools/build_cues_asr.js`）
  1. `tools/transcribe_faster.py` 出词级 `配音.wav.transcript.json`（1010 词）
  2. opencc `t2s` 转简体 → `配音.wav.transcript.simp.json`（whisper 中文默认输出繁体，不转命中率只有 79.7%）
  3. 稿子字流 × ASR 字流做**字符级 LCS**；数字连续 ≥2 位统一掩成 `#`（`二零一八` 与 `2018` 等长）
  4. 命中字符取实际发声时刻，未命中在相邻锚点间线性插值
- **结果**：字符命中 1018/1136 = 89.6%，逐条锚定率 <60% 仅 2 条，字幕窗静音 >35% 的条数 0，无超长/过短，102 条
- **字幕文本新规（用户定）**：不含任何标点；一条内多个小句之间空一格（渲染用固定 GAP=11 px，不依赖字体 advance）
- **交叉验证**：78.13 s 字幕「说得通 所以二零一八年为了申遗」↔ 音频 77.6–79.2 s 实念「一 头 说 得 通 所以 2018」✓

### 五个坑（都要记住）

1. **Windows 必须显式给 GPU 参数**：`MG_GPU_ARGS="--use-angle=d3d11 --no-sandbox"`。默认分支是 Linux 的 `--use-gl=angle --use-angle=gl-egl`，在本机导致 WebGL 页面报 `NetworkError`（且原始 demo 同样失败，容易误判成自己的改动）
2. **`Press Start 2P` 字体不在仓库**：`assets/fonts/latin/pressstart2p/` 为空 → `document.fonts.load` reject → 整片不渲染。网络下载被拦，已把 `fonts.css` 里该字族 src 指到 Fusion Pixel 12 拉丁子集（同仓库）。这是本版与上游的已知字形偏差
3. **不能为了中文 logo 强开 `V5=true`**：V5 是 reel 版式，会额外绘制「圆球」道具并跟随主角，压在人物身上。正确做法：`V5=false` + `LOGO0 = buildLogo5('仁德天皇陵')`
4. **`buildLogo5` 依赖 `C5` 常量**，把构建语句放在 `C5` 声明之前会触发 TDZ（`Cannot access 'C5' before initialization`）。必须在常量之后赋值
5. **上游响度口径是 −14 LUFS**（不是本项目的 −16）；`pyloudnorm` 在 venv 缺失且无 pip，用 numpy 写了 BS.1770 替身放进 site-packages，母带实测 −14.02 LUFS

### 五个坑（通用）

1. **`renderAt` 是对整帧采样，zoom 会把 UI 一起放大**：上游 8–12 倍推镜只放大世界，因为它推镜时没有字幕；本片字幕条常驻，实测 8 倍时 12 px 字变 96 px 高、字幕条吃掉画面 1/4（最近邻放大不糊，是尺寸失控）。要推镜必须把 UI 层挪到放大之后画（改渲染流程），否则只能放弃 zoom
2. **环境槽（`E.*`）会随调色阶段变色**：远景陵墓用 `E.mD` 画，DAY 段 `mD` 是蓝的（SM 表 [5,5,29,10,9,1]），剪影直接变蓝色蘑菇。剪影/道具要用固定 `M(i)` 色
3. **12 px 点阵下阿拉伯数字 0 与 8 难分**：号外卡「2018」被读成「2818」。日期改中文（二〇一八 / 十月十五）才可读
4. **印章内塞 12 px 双字必糊**：「解禁」两个字在 36 px 印面里完全认不出。改单字「禁」+ 上下两道红纹
5. **前景草高度直接决定角色可见性**：`FG` 高 9–13 px 时人物只剩头露出，降到 4–7 px 才看得出跑动姿态
