## 18:20-18:40 配音引擎升级：GPT-SoVITS v3 → v5turbo（用户指令：克隆自己仓库覆盖 vendor）

**做了什么**：把 `git@github.com:DaBaoAgent/gpt-sovits.git`（v5turbo 版）覆盖到 `vendor/gpt-sovits`，保留 `.venv`，恢复本机补丁，端到端验证配音链路。

**关键障碍与解法**
- 仓库 13 个大文件走 Git LFS（2.79 GB），本机无 git-lfs，且 `github.com` 全通道被墙（直连超时/代理 502），`git clone` 走 SSH 能拿到 334 个源码文件但 checkout 失败，工作区只落地 85 个文件
- **可行通道**：`media.githubusercontent.com/media/<owner>/<repo>/<branch>/<path>` 直连可达，返回 LFS 实体；按 HEAD 里 pointer 的 `oid sha256` + `size` 逐个校验（4 并发，约 6 分钟拉完 13/13）
- 补全工作区：`git archive HEAD | tar -x`（先把已下载实体 move 到暂存区，导出后再回填，避免被 pointer 覆盖）
- 临时脚本：`.workbuddy/tmp/{fetch_lfs.py,repair_tree.py,lfs_files.json}`（可复用于下次升级）

**切换序列（可复用）**：旧目录 rename 为 `vendor/_gpt-sovits_v3_backup` → 新目录就位 → `.venv` move 进来（venv 可跨路径迁移，prefix/torch/transformers 验证正常）→ `git reset --mixed HEAD` 校正索引

**本机改造**（上游 preset 硬编码 `D:\GPT-SoVITS`）
- `voices/dabao/preset.json`：ref_audio_path / server.{root,python,api_script,infer_config} / ffmpeg / ffprobe 全改相对路径
- `start-tts-server.vbs`：上游删掉了 `run_capped.py --limit-mb 16384` 的 16GB Job Object 上限，已原样补回（与 v3 版 diff 为零）
- `.venv` 缺 pip 模块（`No module named pip`），不影响运行；缺 funasr 也无影响（仅 ASR 工具用）

**验证结果**
- `/health`：version=v5turbo、weights=s2Gv5turbo.pth、fixes_global=92、fixes_act=[3,4,5]、mp3 192k
- 合成：30 字→5.5s 音频/17.0s 用时；16 字→2.8s/8.6s；稳态 RTF≈3.1x
- 读音纠错生效：许圉师→许禹师（日志打印朗读文本）；act=3 同效
- 端到端 `tools/tts.cmd`：54 字 3 段→7.87s，输出 json 的 chunks 含 text/start/duration，渲染脚本（gen_full_yandi.js 等）兼容
