# 女娲视频背景图 v1

代码绘制（Canvas，零积分），与全片渲染管线同源风格：粗像素噪点纹理 + 近黑深底 + 低饱和。
生成脚本：`yandi-video/render/nuwa/gen_backgrounds.js`（Playwright + bg_page.html，可重复生成、改参数即换风格）。

## 通用设计约束（用户 2026-10-25 裁定）

- **不能太花**：所有视觉兴趣集中在画面四缘/顶/底，**中心 60% 区域保持近黑留空**，供人物与贴图落脚
- 深底 `#0E1518`-`#1D1910` 区间，低对比、低饱和，无亮斑、无镜头光晕
- 全片主色系取样：金 `#E8B84B` / 玉 `#4E9E8A` / 米 `#F3EAD3` / 赭红 `#D9534F` / 土 `#8A5A3B`
- 1920×1080，与正片渲染分辨率一致

## 接入方式

渲染页 `page_full_nuwa.html` 的 `bgBase()` 当前为程序化渐变底；如需替换为图片底，
在 `render(t)` 中按段落 t 加载对应 PNG 作为最底层（`ctx.drawImage` 全幅），
保留其上 `bgParticles / bgTheme / bgStage` 动态层即可，密度指标不受影响。
