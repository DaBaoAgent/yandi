# 002 仁德天皇陵 · 全片分镜表 v2（48 镜 · 逐句对应）

> 2026-10-28 重制。v1 是 26 镜、平均 7.4 秒、按段落粗分，口播词与画面对不上；v2 改为 **48 镜、每镜 2.6–5.1 秒**，
> 切点严格取 `cues_full.json` 每条字幕的 `t0`，因此镜头永不切开一条字幕；每镜画面构件对应该镜口播词说的那件事。

## 规则

1. 切点 = 字幕边界。改字幕必须重算切点（`tools/build_cues_asr.js` 输出后重跑分组）。
2. 每镜必须有一个"主体构件"，画的就是这段词里说的东西；不允许用氛围画面填充。
3. 每镜一段大字（对应口播核心词）+ 一段判词条（补充信息），都从该镜字幕里取词。
4. 构件统一走"暗填充 + 只描边缘受光"，夜景里不用暖色实心块（会变成亮斑）。
